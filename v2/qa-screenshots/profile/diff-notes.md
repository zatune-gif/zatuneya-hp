# profile.html 視覚検証メモ（カンプ対比）

対象カンプ: `00-01_han-ai/design-comps/zatuneya-hp/works-profile-desktop.png`（下段）/ `works-profile-mobile.png`（下段）

## 確認した項目

- ヒーロー構成: 左に丸型の人物写真、右に大きな見出し＋短いリード＋CTAボタンという配置はカンプに一致。
- 色・書体: 背景mint（`--mint`）＋装飾ブロブ、見出しは明朝(`--serif`)大サイズ、本文はNoto Sans JP。カンプの配色トークン（ティール/濃ティール/オレンジ）と一致。
- 横スクロール: 320/375/768/1280pxいずれも横スクロール検出なし。コンソールエラーなし。
- カンプ下部の濃色CTA帯「まずは、今の困りごとを聞かせてください。」はページ末尾に再現（`.bottom-cta`をTOPと共用）。

## 既知の差分・判断（推測ではなく明示した調整）

1. **見出し文言はカンプではなく現行公開ページの文言を維持した**: カンプのPROFILE見出しは「『できること』より、『続けられること』を、一緒に。」（デスクトップ版では右端が見切れ、モバイル版では「『続けられること』を、一緒に…」で見切れており、フルテキストが確認できない）。指示書に「本文は既存ファイルの内容をそのまま移植し、文言を創作しない」と明記されているため、現行 `v2/profile.html` に既にある見出し「『難しそう』を、いっしょに越えていく。」をそのまま維持し、レイアウトのみカンプの様式（丸型写真＋大見出し＋CTA）に合わせた。カンプの文言をそのまま複製すると、確認の取れていない新規コピーを創作することになり指示書の禁止事項に抵触するため、この判断を優先した。
2. **カンプのCTAボタン文言「代表プロフィールを見る→」は採用しなかった**: このボタンはworksページからprofileページへ遷移する導線として設計されたと推測されるが、台帳の割り当てでは同じテキスト/ボタンが「profile.htmlのヒーロー」に対応する。profile.html自身のヒーローに「代表プロフィールを見る」という自己参照リンクを置くと意味が成立しないため、現行 `v2/profile.html` に既にあった実装（AI活用診断への主CTA＋ページ内「経歴を見る」への補助CTA）をそのまま復元し、視覚のみカンプのボタンスタイル（`top-comp.css`の`.btn-orange`/`.btn-outline`）に統一した。
3. **本人写真のクロップ調整**: 既存 `assets/profile-portrait-2.jpg` は単純なポートレートではなく、キャッチコピーやアイコンを含む1枚のポスター画像（900×1349px）。円形マスクにそのまま`object-fit:cover`を適用すると、周囲のコピー文字（「小企業の底力をアップデート」等）が円内に写り込んでしまうことを screenshot で確認したため、CSSの`transform:scale(2.6) / transform-origin:84% 34%`で顔部分のみを拡大トリミングした。新規画像の取得・生成は行わず、既存アセットの表示範囲をCSSで調整したのみ。
4. **既存ページの本文（Story／経歴タイムライン9件／Why／Values／CTA文言）はすべて温存**: カンプの下段クロップはヒーロー部分のみを写しているが、指示書の「本文は既存ファイルの内容をそのまま移植」に従い、現行ページのStory・経歴タイムライン（9項目）・Why（3カード）・Valuesセクション（3カード）の文言は一切変更せず、配色・カード意匠のみ`top-comp.css`のデザイントークンに統一した。
5. 既存ファイルにあった `class=”lead”`（全角引用符によるHTML属性の不備）は、クラス名を`page-lead`に置き換える過程で通常の二重引用符に修正した（表示・機能に影響する既存バグの修正であり、文言自体は変更していない）。
