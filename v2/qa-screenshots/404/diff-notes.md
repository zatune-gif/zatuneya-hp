# 404.html 視覚検証メモ

カンプ: `design-comps/zatuneya-hp/legal-status-desktop.png` / `legal-status-mobile.png`（下段「404 ページが見つかりません」カード＋濃色フッターCTA帯）

## 確認した項目
- ヘッダーはprivacy.htmlと同じ確定版。`<meta name="robots" content="noindex">` は既存どおり維持。
- STATUS見出しブロック（eyebrow「STATUS / ページ状態」、h1「ページが見つかりません」）。
- 白カード2枚: (1) 「404」数字＋「ページが見つかりません」＋「移動したか、URLが異なります。」（カンプの文言を忠実に再現）、(2) 「次の行動」カード（トップへ戻る／無料相談／サービス詳細を見る の3ボタン）。
- 濃色ステータス帯: カンプ最下部と同一構成「404」＋「このページは見つかりませんでした。」＋白アウトライン「トップへ戻る」ボタン。これはカンプで唯一実際に描画されているダークバンドの文言そのものであり、最も忠実度が高い。
- **既知の文字切れ問題への対応**: legal-status-mobile.pngでは「ページが見つかりません」「このページは見つかりませんでした」がカンプ自体の画面幅で右端が見切れている（カンプ制作時の不備と確認済み）。実装では `.legal-title` と `.status-band h2` を `clamp()` フォントサイズ＋通常の折り返しで実装し、375px幅で実際にスクリーンショットを撮って全文が改行表示され、見切れがないことを確認した。
- 320/375/768/1280pxで横スクロールなし、コンソールエラーなし。

## 既存本文との差分
- 既存 `v2/404.html` の案内文（「お探しのページが見つかりませんでした。URLが変更または削除された可能性があります。トップページから目的のページをお探しください。」）はSTATUS見出しブロックのリード文として文言を変更せず保持。
- 既存の2ボタン（「トップページへ戻る」「サービス詳細を見る」）は「次の行動」カードに統合し、「無料相談」ボタンを追加（台帳の必須要件「トップへ戻る／無料相談の両方を含める」に対応）。

## 判断が必要だった点
- なし（カンプの文言・状態がそのまま「404.html」の実際の状態と一致するため、他3ページと異なり文言の作り替え判断は不要だった）。
